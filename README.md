# React Developer Portfolio | Koteswar Singh

A fully responsive personal portfolio website built with React, showcasing my skills, projects, and experience as a Frontend React Developer.

🔗 **Live Demo:**  [https://koti-portfolio-6j7tua501-koteswar-singhs-projects.vercel.app/]
📂 **Repository:** [https://github.com/koti-312/koti-portfolio.git]

---

## ✨ Features

- **Fully Responsive Design** — optimized for desktop, tablet, and mobile screens using custom CSS media queries
- **Smooth Scroll & Hash Routing** — single-page navigation between sections (`#hero`, `#about`, `#skills`, `#projects`, `#contact`)
- **Scroll Animations** — powered by [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/)
- **Sticky Navbar** with mobile hamburger menu
- **Interactive Project Cards** with hover effects, tech stack tags, and live/demo links
- **Contact Form** with input validation styling
- **Clean, Modern UI** with a consistent color palette across all sections

---

## 🛠️ Tech Stack

**Frontend**
- React.js
- JavaScript (ES6+)
- HTML5
- CSS3 (custom responsive styling, Flexbox & Grid)
- AOS.js (scroll animations)

## 📁 Sections

| Section | Description |
|---------|-------------|
| **Navbar** | Sticky navigation bar with logo, menu links, and a "Hire Me" CTA |
| **Hero** | Introduction with profile photo, tagline, and action buttons |
| **About** | Background summary, skills checklist, and resume download |

## 📱 Responsive Breakpoints

The site is built mobile-first with the following breakpoints:

| Device | Max Width |
|--------|-----------|
| Desktop | Default (no media query) |
| Tablet | `1024px` |
| Mobile | `768px` |
| Small Mobile | `480px` |

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/koti-312/koti-portfolio.git

# Navigate into the project directory
cd portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

The site will run locally at `http://localhost:5173`.

### Build for Production

```bash
npm run build
```
